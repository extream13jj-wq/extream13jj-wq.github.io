プライバシーポリシー

MyTube Organizer · 最終更新日：2026年11月3日 · 対象：v0.4.4

MyTube Organizer（以下「本拡張機能」）は、YouTubeの登録チャンネルをフォルダで整理するための個人用Chrome拡張機能です。このページでは、本拡張機能がアクセスする情報と、その保存・利用・削除方法を説明します。

1. 利用するサービスと権限

本拡張機能は、Google OAuth認証および YouTube Data API Services を使用します。YouTube登録チャンネルの取得などのため、利用者の同意に基づいて youtube.readonly（読み取り専用）スコープへのアクセスを要求します。本拡張機能は、動画のアップロード、コメント投稿、チャンネル登録解除などの書き込み権限を要求しません。

2. 取得・参照する情報

登録チャンネルチャンネルID、名前、サムネイル画像のURL、利用者の登録チャンネル一覧。
動画情報利用者がフォルダの更新を実行したときに取得する動画ID、タイトル、公開日時、サムネイルURL、動画種別など。
LIVE表示YouTubeのページ上に既に表示されている登録チャンネルのLIVE状態。追加のAPI呼び出しなしで参照し、表示を切り替えます。
メンバーバッジ利用者がYouTubeのメンバーシップページを開いた際、現在の利用者のアバター付近に表示されたバッジ画像を検出できた場合、その画像のURLと画像データを取得します。加入先や加入期間の全件取得・常時監視は行いません。
設定作成したフォルダ、所属分類、表示順、動画フィルター、整理候補、各種表示設定など。

3. 情報の使用目的

取得した情報は、登録チャンネルの一覧表示、フォルダ別整理、動画一覧の表示、LIVE優先表示、メンバーバッジの表示、管理画面の操作および設定のバックアップ・復元に使用します。広告配信、行動追跡、情報販売、第三者向けの利用者プロフィール作成には使用しません。

4. 保存場所と外部通信

  • 取得したチャンネル情報、フォルダ設定、動画一覧キャッシュ、メンバーバッジ画像は、原則として利用者のブラウザの chrome.storage.local に保存します。Googleへの独自のクラウドバックアップ機能はありません。
  • Google OAuthのアクセストークンはChromeの認証機構を通じて扱い、本拡張機能のフォルダ設定用ストレージやJSONバックアップには保存しません。
  • 利用者が登録チャンネル取得や動画更新を実行すると、GoogleのYouTube Data APIへ必要なリクエストを送信します。
  • 検出されたメンバーバッジ画像を保存する際は、Googleの画像配信ドメイン（yt3.googleusercontent.com または yt3.ggpht.com）から画像を取得します。
  • 本拡張機能の開発者が管理する外部サーバーへ、登録チャンネル情報やメンバーバッジをアップロードする処理はありません。
  • 本拡張機能に広告配信、アクセス解析、独自のCookieによる追跡機能はありません。本紹介サイトは静的ページとしてホスティングされ、閲覧時の通信・ログについてはホスティング事業者側の取り扱いが適用されます。

5. バックアップと保存期間

管理ダッシュボードからJSONファイルをエクスポートすると、フォルダ設定、登録チャンネル情報、取得済みメンバーバッジ画像などが含まれます。ファイルは利用者の操作で端末に保存されるため、第三者へ共有しないよう注意してください。

ローカルの設定情報は、利用者がデータを削除するか、本拡張機能をアンインストールするまで保持される場合があります。動画一覧については、手動更新時に直近7日間を対象として再取得する設計です。

6. アクセス権の取り消しとデータ削除

  • Googleアカウントの サードパーティとの接続管理から、本拡張機能のアクセス権を取り消せます。Googleのセキュリティ設定からも確認できます。
  • 保存されたメンバーバッジ画像は、管理ダッシュボードの「バッジ削除」から個別に削除できます。
  • フォルダを削除しても、YouTube上のチャンネル登録自体は解除されません。
  • 本拡張機能のローカルデータを削除したい場合は、バックアップを必要に応じて保管した上で、Chromeから拡張機能をアンインストールしてください。ダウンロード済みJSONは別途削除が必要です。
  • Googleへのアクセス権を取り消す操作だけでは、端末内に既に保存されたデータが直ちに消えない場合があります。

7. 他社サービスのポリシー

本拡張機能ではYouTube API Servicesを利用します。YouTubeおよびGoogleにおける情報の取り扱いは、Google プライバシーポリシー、YouTube 利用規約等をご確認ください。
